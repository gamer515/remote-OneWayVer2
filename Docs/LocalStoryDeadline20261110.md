# 11월 10일을 기준으로 한 내장 LLM 후보 선별

사용자 요청일: 2026-10-31 (한국 시간). 발표용 Gemma와 모델·프롬프트·실행 설정·프로젝트 구조는 유지한다. 진행 중인 `feature/ai-training`과 기존 미커밋 변경을 보존한다.

## 즉시 실행 목표와 일정 상한

사용자 추가 지시에 따라 목표는 후보 선정을 최대한 빨리 끝내고 소규모 학습까지 진행하는 것이다. 아래 날짜를 기다리거나 단계 사이에 의도적으로 대기하지 않는다. 의미·선택지 개선이 확인된 후보가 나오면 곧바로 승인된 72쌍을 이용한 시험 학습과 1회 소규모 학습을 진행한다. 날짜는 늦어질 경우의 상한 목표로만 사용한다.

| 전체 | 작업 | 목표일 |
|---|---|---|
| 1/5 | 미평가 후보 최대 2개, 입력·버전 고정 | 10/31 |
| 2/5 | 학습 없이 한국어·의미·선택지·형식 평가 | 11/2 |
| 3/5 | 학습 후보 선정 즉시 2단계 시험 → 36단계 소규모 학습 | 후보 확인 즉시 |
| 4/5 | 학습 전후 의미 평가·GGUF·현재 런타임 호환, 모델·설정 고정 | 늦어도 11/7 |
| 5/5 | Unity 저장·다음 회차·실패 처리·분기 회귀 확인 | 11/8~9 |
| 여유 | 재현 실패 수정·발표 최종 점검 | 11/10 |

날짜는 작업 목표이며 자동 실행이나 완료 보장이 아니다. 기준 미달 모델은 일정 때문에 적용하지 않는다. 통과 후보가 없으면 기존 발표 설정을 유지하고 확인된 한계를 보고한다.

## 고정한 후보

- `LiquidAI/LFM2-2.6B`: revision `36ed799f7024ef169ba92ffe184821835e15cc66`. 공식 카드에 한국어, 기기 내 실행, 공식 GGUF 경로가 명시돼 있다. LFM Open License v1.0이며 배포 전 이용 조건을 별도로 검토한다. 복잡하거나 다국어인 요청에서 추론문이 나올 수 있으므로 원시 출력과 시간 제한을 그대로 평가한다. [공식 모델](https://huggingface.co/LiquidAI/LFM2-2.6B), [공식 GGUF](https://huggingface.co/LiquidAI/LFM2-2.6B-GGUF)
- `kakaocorp/kanana-1.5-2.1b-instruct-2505`: revision `7df4bc35ccd610e451809d7106e1c3cf82bfd44c`. 한국어·영어의 소형 지시 모델 비교 후보이며 공식 메타데이터의 라이선스는 Apache-2.0이다. [공식 모델](https://huggingface.co/kakaocorp/kanana-1.5-2.1b-instruct-2505), [공식 발표](https://www.kakaocorp.com/page/detail/11654)

이 두 모델은 기존 프로젝트의 모델 문서·등록·평가 도구에서 발견되지 않았다. 기존 `Qwen3-4B-Instruct-2507`과 Gemma는 이미 평가한 대조 기록으로 보존한다. 새 Qwen 계열은 첫 두 후보가 실패할 경우에만 검토한다.

현재 내장 DLL 두 개에서 `lfm2` 문자열을 찾았다. 이는 지원 코드 존재 가능성을 보여 주는 단서이며 실제 모델 로딩·문법 제약·추론 성공을 증명하지 않는다.

## 첫 시험

`ModelScreeningPlan.json`에 후보·버전·일정·예산을 저장했다. `build_screening_bundle.py`는 기존 입력 자료를 재사용하며 `screen_models.py`는 기존 `evaluate.structure` 검사기를 호출한다. 모델당 41회: 도박꾼 검증 4회, 승인된 Guide 진단 8회, 짧은 말투 진단 4회, 공개 교정 중간 검증 25회. Guide는 새 최종 평가 자료로 주장하지 않는다. 공개 최종 19문장은 사용하지 않는다.

게임·말투 입력의 샘플링·시드·출력 예산은 기존 자료에서 읽는다. 공개 교정은 기존과 같이 greedy로 실행한다. 모델별 네이티브 채팅 템플릿·토크나이저 차이를 기록한다. 권장 샘플링을 시험하려면 기존 공통 비교와 별도의 실험으로 고정한다.

Colab의 같은 NF4 환경에서 추가 학습 없이 선별한다. 원시 출력·기계적 JSON 검사·코드 펜스 제거 진단을 따로 기록하며 편리한 정답만 뽑아 합격 처리하지 않는다. 모델당 전체 15분, 요청당 생성 180초, 연속 두 번 생성 한도에 걸리면 중단한다. 이 시간은 모델 선별 예산이며 로컬 장면 전체 3분 목표의 측정치가 아니다.

결과는 Drive `OneWayTraining/model-screening-20261031`과 로컬 `outputs/AiTraining`에 기록한다. 새 모델이 문법·의미를 지키는 것이 확인되기 전에는 자료 확장·추가 학습·프로젝트 구조 변경·발표용 모델 교체를 하지 않는다.

## 2026-10-31 실제 완료 결과

달력상 목표일까지 기다리지 않고 LFM2 41회, Kanana 6회 선별을 실행했다. 두 모델 모두 게임 품질을 통과하지 못했다. Kanana는 출력 제한으로 선별이 조기 중단되었으며 우수 모델 확정이 아니라 학습 가능성 확인용으로 선정했다. 기존 승인된 공개 66쌍과 게임 6쌍을 그대로 사용해 2단계 시험과 36단계 1회 학습을 완료했고, 어댑터 재로딩에 성공했다.

같은 중간 검증 25문장의 정답 문자열 일치는 7→10개로 증가했지만 일부는 숫자 표기 차이이며, 의미 손실이 남아 있다. 게임 전후 각 4회는 엄격한 구조 통과 0→0으로, 예시 복사·여러 JSON 루트·선택지 명세 객체 출력이 관찰됐다. 품질 미달로 채택하지 않는다. GGUF 변환·내장 런타임·Unity·로컬 전체 180초는 미검증이다. 발표 설정과 공개 최종 19문장은 보존했다. 상세 결과는 `outputs/AiTraining/KananaTrainingSummary.html`과 `KananaTrainingReview.json`에 기록했다.
