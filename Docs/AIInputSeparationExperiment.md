# 입력 구분과 문장 변환 실험

발표용 모델·프롬프트·실행 설정을 유지한다. 기존 모듈이 내보낸 JSON을 실험 파일에서만 변환한다. 정답이나 Explanation을 새로 지어내지 않는다.

## 1. 입력만 바꾸는 비교

`prepare_input_ab.py`는 기존 EvaluationInputs.json의 validation 구간 두 개만 선택한다. `reference`를 `npc_line_reference`, 입력 `options`를 `player_response_specs`, 그 안의 `reference`를 `player_response_reference`로 구분한다. intent·actor·target·상태·말투·난독·semanticText와 빈 의미 항목까지 그대로 유지한다. 역변환으로 원본 JSON과 동등한지 검사한다. 출력은 기존 cards/index/text/options이고 options는 문자열 배열이다. 입력과 출력 역할을 설명하는 지시문이 추가되므로 비교 대상은 필드 이름과 설명을 합친 입력 구분안이다.

같은 고정 revision의 기본 모델에서 LoRA 없이 기존/구분 입력, 두 시드, 두 구간으로 총 8회 생성한다. 기존 evaluate.py의 형식 검사를 재사용한다. raw HF 생성이므로 게임 GBNF와의 비교가 아니다. 클라우드 요청별 180초 한도는 로컬 전체 장면 3분 목표 달성 근거가 아니다. 시간·토큰 상한 도달도 기록한다.

형식, 카드·선택지 개수, 선택 의도, 주체, 사실 추가, 한국어 표현을 각각 검토한다. Explanation 미작성 항목은 기존 원문을 보조 근거로 표시하고 최종 의미 승인을 주장하지 않는다. 최종 평가였던 Duelist는 이번 입력 선택에 사용하지 않는다. 후속 최종 평가에는 새 장면을 확보한다.

## 2. 기존 승인 정답의 보존

6개 정답의 assistant 응답은 바꾸지 않고 입력 변환 후보를 InputSeparationTrainingCandidates.json에 별도 저장한다. 이 파일은 trainingEligible=false이며 현재 TrainingPairs.jsonl이나 학습 번들에 자동 편입하지 않는다. 입력 비교 후 채택 여부를 판단한다.

난독은 교정 오류와 별도 조건이다. Explanation의 semanticText 의미, 누가 정상적으로 말하는지, 누가 알아듣지 못하는지, 사건 전후 상태를 함께 보존한다. 과거 꿈의 인상을 실제 만남으로 바꾸지 않는다. 정상 문장 교정 자료가 이 조건을 덮어쓰지 않도록 일반 교정·말투 변환·난독 보존을 구분해 평가한다.

## 3. 공개 자료 후보

PublicDataCandidates.json에 실제 출처와 편입 상태를 기록했다. AI Hub의 원문 ko/인간 교정문 corrected 쌍을 첫 후보로 삼는다. 데이터 신청과 이용 조건 확인 후 원문·교정문·오류 유형·출처 식별자를 보존해 검토한다. 모두의 말뭉치는 자연스러운 대화 참고 후보이며 바로 변환 정답이 되지 않는다. SmileStyle은 비상업용 조건과 알려진 품질 문제 때문에 현재 학습 후보에서 제외한다.

공개 자료를 확보하면 작은 검토 묶음부터 만든다. 교정 자료만 추가한 실험과 승인된 게임 자료를 함께 사용한 실험을 비교하여 표현 개선이 의미·형식을 해치지 않는지 본다. 임의의 학습량·혼합 비율·장비 적합성을 미리 확정하지 않는다. 요청 분리는 입력 구분 실험 다음 후보이며 전체 장면 누적 시간을 재야 한다.

`import_correction_candidates.py`는 확보한 AI Hub JSON/JSONL의 ko/corrected 쌍과 오류 유형·출처·파일 해시·판본·이용 조건 근거를 보존해 outputs/AiTraining/PublicDataReview 아래에만 내보낸다. 모든 행은 의미 검토 전·미승인·미분리 상태이며 trainingEligible=false다. 정답이 같은 정상 문장도 남겨 과교정 억제 후보로 검토한다. 학습 파일이나 기존 검토 파일을 덮어쓰지 않는다. 현재 공개 원문 다운로드·신규 학습은 수행하지 않았다.

## 실제 비교 결과

2026-10-29 기존 Colab을 T4에 다시 연결하고 고정 패키지·Drive 실험 폴더를 복원해 8회를 완료했다. 복원 셀 실행 전에 발생한 RUN 미정의 오류는 복원 후 재실행하여 해결했다. 원본 모델을 다시 내려받아 적재했고 LoRA는 적용하지 않았다. 입력 파일의 SHA256을 원격 결과와 대조해 일치함을 확인했다.

양쪽 엄격 형식 통과는 각 0/4다. 모든 출력에 코드 블록이 붙었다. 이를 제외하고 내용을 살펴봐도 양쪽 안내 구간은 두 카드를 한 카드로 줄이고 필요 없는 선택지를 추가했으며 원래 조작법을 누락했다. 선택 구간은 양쪽 두 시드에서 원래 네 선택지를 그대로 복사했다. 구분안이 선택지 문제를 해결했다고 주장하지 않는다. 평균 클라우드 생성은 기존 10.33초, 구분안 9.87초이나 네 건씩인 탐색 결과이며 속도 개선 근거로 채택하지 않는다. 로컬 전체 장면 180초는 미검증이다.

결과는 InputSeparationReview.json과 outputs/AiTraining/InputComparison.html에 기록했다. 입력 구분안은 채택하지 않고 격리된 후보로 유지한다. 후속 자료에는 정상 교정·의미 유지 말투 변환뿐 아니라 여러 카드의 순서·개수와 선택지별 의도를 유지하는 사례가 필요하다. 실제 공개 자료 확보와 정답 검토 후에만 새 학습을 시작한다.
