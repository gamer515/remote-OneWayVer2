# 3D 맵 편집 툴

메뉴: **Tools > Dungeon > 3D Map Authoring**

기존 `DungeonRandomGameObjectBrush`를 사용하며, 기존 Tile Palette와 브러시 에셋도 유지한다.
새 편집창은 에셋 폴더의 FBX·프리팹을 썸네일로 보여준다. 에셋별 브러시 파일을 추가 생성하지 않는다.

## 던전·캐슬 등 에셋 팩 전환

**3. 타일 / 오브젝트 선택 > 에셋 팩**에서 사용할 팩을 선택한다.
`Assets/UnityAssets/Buildings_And_Terrains` 바로 아래 폴더들을 자동으로 검색한다.
예를 들어 `Castle_FBX format` 폴더를 임포트하면 **캐슬**이 목록에 추가된다.
프로젝트 변경 시 목록이 갱신되며, **에셋 팩 목록 새로고침**으로 직접 갱신할 수도 있다.

다른 위치의 에셋은 **에셋 폴더** 칸에 폴더를 넣고 **사용자 에셋 팩 등록 / 변경**을 펼친다.
팩 이름을 입력한 뒤 **현재 폴더를 팩으로 등록 / 이름 변경**을 누르면 전환 목록에 저장된다.
같은 폴더를 다시 등록하면 표시 이름을 바꿀 수 있다. 등록 해제는 원본 에셋을 삭제하지 않는다.
폴더는 GUID로 기억하므로 Unity Project 창에서 폴더 이름·위치를 변경해도 연결이 유지된다.

팩을 바꾸면 이전 타일 선택과 검색어가 초기화된다. 이미 배치한 오브젝트는 유지되므로 같은 청크에 여러 팩을 섞어 쓸 수 있다.
새 팩은 현재 배치 배율과 간격을 사용하므로 원본 모델 크기에 맞춰 조절한다.
등록 이름과 마지막 선택은 `UserSettings/DungeonMapAssetPacks.asset`에 기기별로 저장한다.
새 씬·프리팹·브러시·모델 파일은 만들지 않는다.

## 새 청크 만들기

1. 크기 X/Z에 `50`, `120`을 입력한다. 단위는 Unity units이다.
2. 새 청크 위치와 타일 간격을 지정한다. 기본 간격은 기존 던전 에셋에 맞춘 `2.8`이다.
3. 필요하면 기존 그라운드 재질을 지정한 뒤 **새 청크 + 평평한 그라운드 생성**을 누른다.

그라운드는 두께 1의 단일 Cube와 BoxCollider이며, 윗면 높이가 청크 원점이다.
중앙 기준 X는 -25~25, Z는 -60~60이다. 다음 청크 원점을 Z 방향으로 120 옮기면 이어진다.
바닥 타일을 자동으로 수천 개 생성하지 않으며, 씬·프리팹·재질 파일도 자동 저장하지 않는다.

## 배치

1. 작업 청크, 층, 층간 높이, 레이어를 선택하고 **선택한 층 / 레이어 준비**를 누른다.
2. 썸네일을 클릭하거나 선택한 타일 칸에 프로젝트의 FBX·프리팹을 넣는다.
3. 크기 배율 X/Y/Z, 높이 오프셋, 회전을 지정한다.
4. **Scene 배치 모드**를 켜고 Scene에서 클릭하거나 누른 채 드래그한다.

배율은 원본 프리팹 크기에 곱해진다. 높이 오프셋은 해당 층의 바닥 기준이다.
초록 와이어 박스는 배치될 메시의 크기·회전을 보여준다. 피벗이 바닥 중앙이 아닌 모델은 높이 오프셋으로 맞춘다.
타일 선택 후 마우스를 떼고, Scene에서 새로 드래그를 시작한다.

- **Shift + 드래그**: 현재 층·레이어만 지운다.
- **R**: 90도 회전한다.
- **Esc**: 배치 모드를 종료한다.
- **Ctrl+Z / Ctrl+Y**: 한 획 단위 실행 취소 / 다시 실행.
- **Alt + 마우스**: 기존 Scene 카메라 조작.

같은 층·레이어의 같은 칸은 중복 배치하지 않는다. 서로 다른 레이어는 같은 칸에 놓을 수 있다.
생성한 그라운드 밖에 중심이 있는 칸은 배치하지 않는다. 모델 크기에 따른 충돌·겹침 판정은 하지 않는다.

## 층과 레이어

```text
MapChunk_50x120
├── Ground
└── DungeonAuthoringGrid
    ├── Floor_01
    │   ├── FloorTiles     바닥 타일
    │   ├── Structures     건물
    │   ├── Nature         나무·바위 등 자연물
    │   └── Decorations    장식
    └── Floor_02           필요할 때 생성
        └── Structures     선택한 레이어만 생성
```

층간 높이가 4이면 2층은 +4, 3층은 +8이다. 이미 만든 층은 이후 설정 변경으로 움직이지 않는다.
기존 층의 높이는 Hierarchy에서 `Floor_02` 등의 Y 위치를 바꾸면 해당 층 전체가 함께 이동한다.
레이어는 편집용 Grid 그룹이다. 프로젝트 전역 Unity Layer 및 충돌 설정은 바꾸지 않는다.

기존 청크는 `DungeonAuthoringGrid`가 있으면 재사용하며, 1층의 기존 레이어도 그대로 이용한다.
**배치 대상 Grid**에 기존 `FloorTiles`, `Structures`, `Decorations`를 직접 지정해도 된다.
새 창은 바닥을 XZ 평면으로 사용하는 `XZY` Grid를 대상으로 한다.

작업한 청크는 사용자가 씬을 저장하거나 Hierarchy의 청크 루트를 Project 창으로 드래그해 새 프리팹으로 저장한다.
공통 씬·프리팹에 반영하기 전에는 담당을 조율한다. `.meta`도 함께 관리한다.

## 검증

```powershell
unity command run_script --file AgentScripts/DungeonMapAuthoringCheck.cs --entry DungeonMapAuthoringCheck.Regression --format json
```

임시 씬에서 그라운드 크기, 층·레이어 분리, 배율·높이·회전, 미리보기 좌표, 삭제, Undo/Redo 등을 검증하고 임시 씬을 닫는다.
