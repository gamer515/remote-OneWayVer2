# 공개 한국어 교정 소규모 실험

전체 진행은 `outputs/AiTraining/TrainingProgress.html`에서 확인한다.

1. 공개 자료 선별·원본 글 단위 분리
2. 소규모 학습·미학습 문장 비교
3. 입력 길이·지시 혼재 비교
4. Explanation 기반 게임 자료 보완
5. 변환·Unity 품질 및 로컬 180초 검증

## 이번 자료

KoLLA v2의 두 주석자 교정이 일치하는 후보 176쌍을 검토했다. 의미가 명확한 115쌍 중 원본 글에 유일하게 대응하는 110쌍을 사용한다. 원본 글 64개를 묶음으로 나누고 동일한 원문·교정문이 분리에 걸치지 않도록 검사했다. 학습 66쌍, 중간 검증 25쌍, 최종 평가 19쌍이다. 최종 평가는 학습 및 설정 선택에 사용하지 않는다.

사용자가 공개 자료 선별·실행을 요청한 범위에서 발행된 사람의 교정과 에이전트 의미 검토를 사용한다. 개별 문장에 사용자가 정답 승인을 했다고 기록하지 않는다. 게임용 생성 정답은 기존 사용자 승인 절차를 유지한다.

원본 XML의 학습자 개인정보는 전송하지 않는다. 문장 쌍과 원본 글 식별자만 사용한다. 원본·선별 파일 해시와 분리는 `PublicCorrectionSplitManifest.json`, 선별 기준은 `PublicCorrectionSelection.json`에 기록한다. 자료는 GPLv3 계열로 공개되어 있으며 원본 저작권 표시·라이선스·변형 내역을 번들에 포함한다. 이 실험은 게임 배포용 모델 채택을 의미하지 않는다.

## 실행 및 분리

`finalize_public_review.py` → `build_public_bundle.py` 순서로 기존 다운로드 자료에서 번들을 생성한다. `public_train.py`는 기존 `train.py`의 준비·학습·저장 기능을 재사용하고 공개 자료 진입점에서만 검증기를 지정한다. 게임 학습기의 승인 검사는 수정하지 않는다.

별도 Drive 경로 `OneWayTraining/public-korean-correction-v1`에 저장한다. 기존 `experiment-001`은 보존한다. 2단계 시험 학습을 통과한 뒤 33단계(66쌍 1회) 실험을 진행한다. 게임 학습용 설정 파일과 발표용 설정은 수정하지 않는다.

`evaluate_public_correction.py`는 중간 검증 25쌍에 대해 동일한 디코딩 설정으로 원본·어댑터를 번갈아 평가한다. 정답 문자열 일치·문자 편집 거리는 보조 지표이며 의미와 자연스러움은 실제 출력을 검토한다. Colab 실행 시간은 로컬 게임의 장면 전체 180초 목표를 검증하지 않는다.

## 실행 결과 (2026-10-30)

공개 자료만 학습한 33단계 실험은 저장·재로딩을 통과했다. 중간 검증 25문장의 발행 교정문과 정확 일치는 원본 5개, 어댑터 8개였다. 늘어난 3개는 주로 원래 말끝을 유지한 차이였으며 광범위한 문법 개선으로 해석하지 않는다.

기존 입력에서 `examples`만 비우는 비교 8회도 실행했다. 카드 누락이 남고 선택지 명세 객체를 복사해 입력 변경은 채택하지 않았다. 이 비교는 예시 정보와 입력 길이를 함께 바꾸므로 순수 길이 효과를 증명하지 않는다.

사용자가 NPC 새 문구 `내에 마알이 무우슨 뜨신지 모오르겠지이?`를 승인했다. Explanation의 `알아듣지 못하겠지?` 의미와 기존 네 선택지를 유지했다. 기존 `ExportTrainingReview`를 실제 Unity에서 실행해 입력을 다시 생성했고 6/6 구조·상황·길이 검증을 통과했다. 이전 자료와 실험은 별도로 보존했다.

`mixed_train.py`는 공개 자료와 게임 자료를 각각 기존 검증기로 검사한 뒤 72쌍을 한 번 학습했다. 새 Drive 경로는 `OneWayTraining/public-game-correction-v1`이다. 36단계 학습·어댑터 재로딩을 통과했으며 최고 할당 VRAM은 10.76 GiB였다. 현재 6GB 로컬 장비에서 같은 학습 조건이 가능하다고 가정하지 않는다.

혼합 모델의 일반 교정 정확 일치는 10/25, 문자 편집 거리 합은 44(원본 95)였다. 다른 올바른 표현도 있어 일치율을 문법 정확도로 해석하지 않는다. 도박꾼 검증 8회에서는 카드 누락·임의 보상·선택지 명세 복사가 남아 게임용 품질 개선을 확인하지 못했다. GBNF 없는 HF 원시 출력의 엄격한 JSON 통과는 양쪽 0/4, 코드 펜스를 제거한 진단용 구조 통과는 양쪽 2/4였다. 어느 지표도 Unity 전체 실패율이 아니다.

따라서 5단계 변환·게임 적용은 품질 기준 미달로 보류했다. 고정 대상 99개 파일은 그대로다. 로컬 장면 전체 180초, 실제 저장 및 다음 회차·분기 적용은 아직 검증하지 않았다. 공용 최종 19문장과 새로운 게임 최종 평가 장면은 이 실험에서 사용하지 않았다. 다음 판단은 자료를 무작정 늘리기 전에 동일 검증 입력으로 다른 기반 모델을 비교하는 것이다.

`PilotExecutionStatus.json`에 채택 판단을 기록했다. `OneWay_PublicCorrection_Pilot.ipynb`는 출력·토큰·모델 없이 재실행 코드를 담고 있다. 기존 실험의 입력 해시를 수정하지 않는다. `outputs/AiTraining/PilotSummary.html`에서 실제 비교 출력으로 이동할 수 있다.
